Aim: To simulate CPU scheduling algorithms (FCFS, SJF, SRTF and Round Robin) and calculate the completion time, turnaround time and waiting time of each process, along with their averages.

Formulas:

Turnaround Time (TAT) = Completion Time (CT) - Arrival Time (AT)
Waiting Time    (WT)  = Turnaround Time (TAT) - Burst Time (BT)
FCFS
1. Sort processes by arrival time
2. time = 0
3. for each process p in order:
     if time < p.AT then time = p.AT      // CPU idle
     time = time + p.BT
     p.CT = time
     p.TAT = p.CT - p.AT
     p.WT  = p.TAT - p.BT
4. Print table and averages

SJF (non-preemptive)
1. time = 0, done = 0
2. while done < n:
     ready = processes with AT <= time and not finished
     if ready is empty: time = next arrival; continue
     pick p in ready with smallest BT
     time = time + p.BT; p.CT = time
     mark p finished; done = done + 1
3. Compute TAT and WT for all

Round Robin (quantum Q)
1. queue = [], add processes as they arrive
2. while queue not empty:
     p = dequeue()
     run = min(Q, p.remaining)
     time = time + run; p.remaining -= run
     enqueue processes that arrived up to now
     if p.remaining > 0 then enqueue(p) else p.CT = time
3. Compute TAT and WT

FCFS

#include <stdio.h>
int main() {
    int n, at[20], bt[20], ct[20], tat[20], wt[20];
    float sw = 0, st = 0;
    printf("Enter number of processes: ");
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        printf("P%d arrival and burst time: ", i + 1);
        scanf("%d %d", &at[i], &bt[i]);
    }
    /* sort by arrival time */
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - i - 1; j++)
            if (at[j] > at[j + 1]) {
                int t;
                t = at[j]; at[j] = at[j + 1]; at[j + 1] = t;
                t = bt[j]; bt[j] = bt[j + 1]; bt[j + 1] = t;
            }
    int time = 0;
    for (int i = 0; i < n; i++) {
        if (time < at[i]) time = at[i];
        time += bt[i];
        ct[i]  = time;
        tat[i] = ct[i] - at[i];
        wt[i]  = tat[i] - bt[i];
        sw += wt[i]; st += tat[i];
    }
    printf("\nP\tAT\tBT\tCT\tTAT\tWT\n");
    for (int i = 0; i < n; i++)
        printf("P%d\t%d\t%d\t%d\t%d\t%d\n", i + 1, at[i], bt[i], ct[i], tat[i], wt[i]);
    printf("Avg TAT = %.2f\nAvg WT  = %.2f\n", st / n, sw / n);
    return 0;
}

Round Robin

#include <stdio.h>
int main() {
    int n, q, at[20], bt[20], rem[20], ct[20], queue[200];
    int head = 0, tail = 0, time = 0, done = 0, seen[20] = {0};
    printf("Enter n and quantum: ");
    scanf("%d %d", &n, &q);
    for (int i = 0; i < n; i++) {
        scanf("%d %d", &at[i], &bt[i]);
        rem[i] = bt[i];
    }
    while (done < n) {
        for (int i = 0; i < n; i++)          /* admit arrivals */
            if (!seen[i] && at[i] <= time) { queue[tail++] = i; seen[i] = 1; }
        if (head == tail) { time++; continue; }   /* CPU idle */
        int p = queue[head++];
        int run = rem[p] < q ? rem[p] : q;
        time += run; rem[p] -= run;
        for (int i = 0; i < n; i++)
            if (!seen[i] && at[i] <= time) { queue[tail++] = i; seen[i] = 1; }
        if (rem[p] > 0) queue[tail++] = p;
        else { ct[p] = time; done++; }
    }
    float st = 0, sw = 0;
    printf("\nP\tAT\tBT\tCT\tTAT\tWT\n");
    for (int i = 0; i < n; i++) {
        int tat = ct[i] - at[i], wt = tat - bt[i];
        st += tat; sw += wt;
        printf("P%d\t%d\t%d\t%d\t%d\t%d\n", i + 1, at[i], bt[i], ct[i], tat, wt);
    }
    printf("Avg TAT = %.2f\nAvg WT  = %.2f\n", st / n, sw / n);
    return 0;
}

What is a Gantt chart?

A bar chart of time on the CPU. Each block shows which process ran and for how long.

What is the convoy effect?

In FCFS, short processes wait behind one long process, which raises average waiting time.

Which algorithm gives the minimum average waiting time?

SJF (and SRTF in its preemptive form) is provably optimal for average waiting time, but it can starve long processes.

How does the time quantum affect Round Robin?

A very large quantum makes RR behave like FCFS. A very small quantum causes too many context switches and wastes CPU time.

What is the difference between preemptive and non-preemptive scheduling?

A preemptive scheduler can take the CPU from a running process (SRTF, RR). A non-preemptive one lets it finish its burst (FCFS, SJF).

What does the CPU do when no process is ready?

It sits idle. The simulator draws these gaps as hatched "idle" blocks.
